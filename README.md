# 內掃區檢查（教室）

和「外掃區檢查地圖」同一套設計：手機、平板、電腦都能用的教室內掃檢查網頁，另外加上**加扣分**、**工作分配與幹部名單**、**座位表與選位**、**隨機抽籤**，以及一鍵切換的**學生視角／老師視角**。

- 純靜態網頁，放在 **GitHub Pages**；後端是 **Google Apps Script**（資料在你自己的 Google 帳號）
- **GitHub 上不會出現任何同學姓名或身分證字號**（預設座位、預設幹部都只寫座號）
- 還沒設定雲端之前，密碼輸入 `test` 就能用示範名單試玩所有功能
- 加到手機主畫面後，**每次打開都會自動拿最新版本**（`sw.js`：有網路一律抓最新檔案，沒網路用上次存的）

## 登入

| 身分 | 怎麼登入 | 可以用 |
|---|---|---|
| 導師 | 「老師／幹部」→ 輸入密碼（`Code.gs` 的 `TOKEN`） | 全部功能 |
| 環保股長 | 「老師／幹部」→ 自己的身分證字號 | 掃地檢查（內掃）、加扣分、工作分配、座位、抽籤 |
| 外掃監督A／B | 「老師／幹部」→ 自己的身分證字號 | 掃地檢查（外掃南區／北區）、工作分配、座位、抽籤 |
| 其他幹部 | 「老師／幹部」→ 自己的身分證字號 | 加扣分、工作分配、座位、抽籤 |
| 學生 | 「學生選位」→ 自己的身分證字號（網址加 `#seat` 會直接開這一頁） | 座位（選位）、工作分配、商店 |

- 身分證字號首字母大小寫都可以，全形、空白也會自動處理。
- 幹部是誰由導師在「👥 工作分配 → 🎖 幹部名單 → ✏️ 修改幹部名單」設定；不在名單上的人用身分證字號登入「老師／幹部」會被拒絕。
- 幹部、學生登入後 30 天內有效（手機上不會存身分證字號）。有人手機遺失時，可以在試算表選單「內掃檢查 → 讓所有人重新登入」讓全部登入失效。

## 功能

| 分頁 | 說明 |
|---|---|
| 🧹 掃地檢查 | 上方切換 **🏫 內掃區／🌳 外掃區**。點平面圖（外掃是走廊圖表）上的物件或名牌，記錄「好／不好／未出席」、有狀況、拍照；「匯出報表」彙整並傳 LINE。內掃、外掃的「不好」都寫入這個 App 的試算表 |
| ⚖️ 加扣分 | 選「扣分／加分」、分數、類別（秩序／整潔／其他）、**一定要寫理由**，點選一位或多位同學後送出。登記人由登入身分自動記錄，不能冒名。幹部只看得到、只能刪除自己登記的；導師看得到全部 |
| 👥 工作分配 | 平面圖（點物件看負責同學）。「全部工作」「🌳 外掃區工作分配」「幹部名單」預設收起來，點一下展開；導師可以修改 |
| 🪑 座位 | 見下方 |
| 🛍 商店 | 同學用加分得到的點數買大頭照配件，可以自己戴或送人；配件有效 10 個上課日。導師看得到全班點數 |
| 💬 LINE 圖 | 用自己的大頭照（含配件）加上文字（思源柔黑體粗體，可選顏色、大小、位置），做成圖片直接分享到 LINE 群組 |
| 🎲 抽籤 | 一次抽 1–10 人、只抽某一科、抽過的不再抽、設缺席；可全螢幕投影，空白鍵／簡報筆也能抽 |

**學生視角／老師視角**：右上角一按就切換。學生視角＝黑板在上方；老師視角＝整張圖轉 180 度（從講台往學生看），文字仍是正的。

### 🌳 外掃區（和舊的「外掃區檢查」App 並存）

- **工作分配同步**：這個 App 直接讀寫外掃 App 試算表裡的「工作分配」工作表，所以兩邊看到的是同一份。第一次使用：導師到「👥 工作分配 → 🌳 外掃區工作分配」貼上外掃試算表的網址（兩份試算表要在同一個 Google 帳號）。
- 外掃區畫成走廊圖表，**導師點名字就能換人**；已經有室內或外掃工作的同學不會出現在選單裡。在外掃 App 修改，這裡也會跟著變。
- **外掃檢查紀錄**寫進這個 App 的試算表（處所會寫「外掃 公佈欄玻璃 1」），扣分統計的「整潔」欄會把內掃和外掃合在一起。舊的外掃 App 如果繼續使用，紀錄仍寫在它自己的試算表。
- 外掃監督A（外掃試算表的 I1）只能檢查南區、外掃監督B（I2）只能檢查北區；導師全部都可以。

### 🛍 商店與大頭照裝飾

- **點數**＝這個人所有「加分」的總和 − 買配件用掉的點數。扣分不會減少點數。
- **配件**：內建 12 種（墨鏡、皇冠、貓耳…），另外可以把去背的 PNG 放到雲端硬碟「內掃檢查／配件」資料夾，檔名「名稱_價格.png」（例如 `墨鏡_3.png`，沒寫價格＝3 點；每張 400 KB 以內）。約 10 分鐘內出現在商店。
- **有效期限**：從購買那天起算第 10 個上課日（週一到週五；國定假日不會自動扣除）。過期後自動從大頭照上消失。
- **送人**：送出後到期日不變，不能收回。
- **🦹 竊盜卡（10 點）**：把別人的一個配件變成自己的（到期日不變），對方打開商店會看到通知。
- **🔀 交換位置卡（20 點）**：和另一位同學強制對調座位（兩人都要已經有座位），對方打開商店會看到通知。
- **🎆 煙火（1 點）**：放在某位同學的座位上，每個人下次打開 App 時，在座位表上看到一次（3 天內有效）。
- 價格可以在 `Code.gs` 的 `CONFIG`（`STEAL_PRICE`、`FIREWORK_PRICE`）修改；紀錄在試算表「點數使用」。
- **裝扮**：「🎨 裝扮大頭照」可以拖曳移動、兩指縮放旋轉，也可以用滑桿調整大小和角度。底圖仍然是雲端硬碟的大頭照。裝扮會出現在座位表、抽籤等所有顯示大頭照的地方。
- 點數檢查、價格、配件是誰的、有沒有過期，全部由 Apps Script 判斷，學生無法從網頁作弊。紀錄在試算表「配件」「大頭照裝飾」。

### 🪑 座位

- 分頁：📋 座位表（只看，點大頭照放大、再點一次關閉）／🎯 現場選位／🗳 線上選位／🔁 交換位置（導師）。座位圖只畫黑板、講桌、前後門。
- **座位表**：每格是同學的大頭照（滿版），底下兩行小字「組別 座號」「姓名」。第一次打開會自動套用你提供的預設座位，之後可按「↺ 恢復預設座位」。
- **換座位**（🔁 交換位置）：點一個同學，再點另一個同學 → 兩人互換；點空位 → 搬過去。下方浮動列會顯示他的掃地工作；「詳細」可以看大圖並登記加扣分，「✏️」可以用選單換人或上傳大頭照。還沒有座位的同學列在下方，點名字再點座位就能放進去。
- **🎯 現場選位**（依名單順序）：上傳名單（Excel／CSV／文字檔，或直接貼上）→ 按「開始」先清空所有座位（原本的會備份，可以還原）→ 第 1 位點一個座位、接著第 2 位、第 3 位…，可以「復原」「跳過（移到最後）」。名單有「名次」欄就依名次排，沒有就照上下順序。名單格式很寬鬆：`料 24 王小明`、分成 科別／座號／姓名 三欄、或只有姓名都可以。名單只在這台裝置上讀取，不會上傳。
- **🗳 線上選位**（學生各自用手機選）：依段考名次輪流，可以先預選志願、時間到自動移到最後。步驟見下方。
- **大頭照**：座位表下方「📁 大頭照資料夾」貼上雲端硬碟資料夾連結即可。照片檔名用「組別座號姓名」，例如 `料 24 王小明.jpg`、`多 11 陳小華.jpg`，會依組別＋座號放到對應同學的座位。那個資料夾只會被讀取，不會被改動。也可以在座位上直接上傳。

### 線上選位（依段考名次）

1. 排名放在雲端硬碟「內掃檢查」資料夾，檔名含「排名」或「成績」的 Google 試算表（多份時用最新修改的）。欄位：`名次`、`科別`、`座號`、`姓名`，可以有 `身分證字號`。
2. 導師：🪑 座位 → 🗳 線上選位 → 選每人時間與志願數 →「📥 讀取段考排名」。可以把座位設「不開放」或先指定給某位同學。
3. 學生用 `網址#seat` 登入，先點座位排志願；導師按「▶ 開始選位」後依名次輪流，志願還有空位就立刻自動分配。
4. 結束後按「✅ 套用到座位表」。

## 試算表

- **扣分統計**：全班名單，欄位「整潔不好次數、整潔、秩序、其他、合計、明細」。整潔＝掃地「不好」扣分＋加扣分中「整潔」類；合計為負整列標紅、為正標綠。按按鈕或勾 B6 重新計算，可設定起訖日期與每次「不好」扣幾分。
- **加扣分紀錄**：日期、同學、分數（負＝扣分）、類別、理由、登記人、登記時間。可以直接在試算表修改。
- **檢查紀錄**：掃地「不好」的紀錄（和外掃相同）。
- **工作分配**：掃地工作、環保股長（I1）、幹部（C1…）。
- **座位表**、**選位紀錄**。

## 一、放到 GitHub Pages

1. 建立 repository（例如 `indoor-cleaning-map`），把這個資料夾的所有檔案上傳（包含 `sw.js`）。
2. **Settings → Pages**：`Deploy from a branch`、`main`、`/ (root)`。

## 二、連接 Google 試算表與雲端硬碟

1. 建立一份**新的** Google 試算表（不要和外掃共用）。
2. **擴充功能 → Apps Script**，貼上 [`gas/Code.gs`](gas/Code.gs)，把 `CONFIG.TOKEN` 改成導師密碼。
3. 執行 `setup`，完成授權。
4. 在「內掃檢查」資料夾放入**名單試算表**：`科別`、`座號`、`姓名`、`身分證字號`（幹部和學生登入都靠這一欄）。
5. **部署 → 新增部署作業**：網頁應用程式，執行身分「我」，存取「所有人」。把 `/exec` 網址填進 [`config.js`](config.js)。
6. 用導師密碼登入 → 👥 工作分配 → 🎖 幹部名單 → ✏️ 修改 →「儲存到雲端」（第一次會自動帶入預設幹部），再設定「修改負責人員」。
7. 👥 工作分配 → 🌳 外掃區工作分配 → 貼上外掃 App 的試算表網址 →「連結外掃區」。

> 修改 `Code.gs` 後要「部署 → 管理部署作業 → 編輯 → 版本：新版本」才會生效。**密碼不要寫進 GitHub 上的檔案。**

## 隱私與安全

- 身分證字號只在你的 Apps Script 裡比對（加鹽雜湊），不會傳回網頁、不會存在手機、不會上 GitHub。猜錯會故意延遲回應。
- 加扣分的登記人由伺服器依登入身分記錄，幹部無法冒用別人的名字；但知道別人身分證字號的人仍可冒用，請提醒幹部不要外流。
- 大頭照只有登入的人看得到。

## 測試模式

密碼欄輸入 `test`：去識別化的示範名單，所有功能都能操作，不會寫入雲端。可以在登入畫面選「導師」或任一位示範幹部；⚙ →「切換使用人」可以換人。按上方「結束測試」清除測試資料。

## 修改

- [`js/map-data.js`](js/map-data.js)：平面圖、工作、座位、預設座位（`defaultSeats`）、幹部職位與預設人選（`cadreSlots`）、加扣分類別與常用理由。
- 選位規則在 [`js/sel-engine.js`](js/sel-engine.js)，`gas/Code.gs` 最下方有一模一樣的一份，**修改時兩邊要一起改**。
