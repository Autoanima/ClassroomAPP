# 2026/10/23 更新與部署

這次同時修改網站和 Google Apps Script 後端。只更新 GitHub 網站檔案，無法啟用新的扣分、禮物、孵蛋器與站內信規則。

## 部署既有 Apps Script 專案

1. 將 `gas/Code.gs` 更新到既有 Apps Script 專案，保留原本班級的 `CONFIG` 設定值（例如試算表代號、導師密碼、網站網址）。其他引擎檔案維持原有版本。
2. 手動執行一次 `setupFeatureUpdates()` 並完成 Google 授權。這會建立幹部週次紀錄與每小時執行一次的觸發器；重複執行不會重複安裝。
3. 在「部署 → 管理部署 → 編輯」選擇新版本，更新原本的網頁應用程式部署，網址不必更換。
4. 手機重新整理網站。先用導師帳號確認新按鈕，再用外掃監督帳號確認加扣分分頁。

幹部提醒的觸發器必須由導師或原本的 Apps Script 專案擁有者安裝。沒有觸發器時，讀取站內信仍會補做檢查，但不能保證週五無人開啟 App 時準時寄送。

## 規則

- **假卡上傳錯誤**：僅導師可標示，包括已確認後才發現錯誤的假卡。保留原照片、取消原上傳的停扣效果，依原登記時間滿 3 天後補算並持續計算每日扣分，另記一筆 −0.3 分。重新上傳後停算；同一輪上傳重複點選不會重複扣 0.3 分。再次上傳仍錯誤，可再次標示。
- **作業與繳交追蹤**：每天 −0.2 分，不滿一天算一天，繳交後停止。現有追蹤項目的逾期計算也使用此費率。假卡原有每日 −0.1 分維持不變。
- **幹部權限**：兩位外掃監督與現有幹部、小老師都能對全班（包含自己）登記加扣分。
- **每週幹部鼓勵**：週一至週日為一期，週五寄一次站內信提醒。幹部可按「本週幫自己加 1 分」，或正常替自己登記至少 +1 分。以實際登記時間判斷週次，他人加分不算完成。下週開始後，未完成者每週 −0.1 分；重跑不重複扣。不追扣功能啟用前的週次。
- **禮物盒**：保留原隨機獎品，每位學生／幹部每盒加贈商店 3 點與一顆蛋。3 點不列入成績加分。原有寵物空間滿額時，蛋保留待領，之後進入寵物頁會自動補領。已開過的盒子不重複發放，也不回溯加贈。
- **公布欄**：每則可設定「這週不再自動顯示」，依帳號同步，週一恢復。手動開啟公布欄仍看得到並可改回持續顯示。原有最近 14 天的公告範圍維持不變。
- **請假標示**：依當日請假日期顯示，掃區地圖用粗體暫停符號標示，外掃名牌以暫停符號替代姓名；座位表在名字上方、同一座位格內顯示假別。部分節次請假也會標示，詳情保留節次。
- **孵蛋器**：商店每個 5 點，先買入庫存，再到寵物頁選自己的蛋使用。待孵與孵化中都能使用，揭曉後不能使用。每次成功率 ×2，10% → 20% → 40% → 80% → 100%；達 100% 後禁止再消耗。道具使用與扣點都在後端檢查。

## 驗證

執行 `node --test tests/*.test.cjs`。測試以模擬試算表驗證假卡補扣與防重複、權限、跨週結算與提醒、公告週期、禮物加贈、點數入帳及孵蛋器實際孵化判斷，另檢查公告操作與座位標籤的產生。正式 Google 試算表與觸發器需要部署後確認。
