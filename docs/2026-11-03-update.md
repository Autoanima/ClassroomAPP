# 2026-11-03 段考獎勵更新

- 段考獎勵改依科內名次：多媒科前 2 名、資料科前 3 名，每人各 1 張交換位置卡，不使用加扣分後的班名次。
- 每學期每次段考只發一次，鎖定後修改名次或重複公布不重發；僅公布排名時發獎，開商店不發獎。
- 兼容舊版同學期已發出的段考獎勵，不因升級補發，也不更動既有道具。
- 現場選位下的排名說明重寫，分別說明混合排序、加扣分期間與各科段考獎勵。
- 測試涵蓋發獎名額與張數、名次變更、重複執行、發獎標記遺失、下一次段考、新學期及舊紀錄相容。

## 新增孵蛋器獎勵

- 該次段考綜合班名次前 10 名，每人 5 個孵蛋器，可與科內名次的 1 張交換位置卡兼得。
- 每次段考孵蛋器獎勵獨立防重複，既有交換位置卡紀錄不會阻擋新增獎勵；於公布排名時發放。
- 在現場選位說明明確列出兩項獎品名稱、數量與排名依據。

## 禮物盒完整說明與持有道具半價賣出

- 禮物盒維持固定 3 點、1 顆寵物蛋及 1 項隨機獎品；商店與放盒視窗補齊隨機種類、每盒一次及蛋滿額保留說明。
- 商店新增「賣出我的道具」，本人持有的未使用卡片、孵蛋器、有效配件與交通工具可逐件依目前定價半價賣出；獎勵或贈品亦適用。半點數依實際半價記帳。
- 單筆記帳同時扣庫存與入點，不影響班級加分；賣出配件不再顯示裝飾，交通工具卸下，保留原購買紀錄。
- 已使用效果、過期配件與寵物本身不列為可售道具。

## 共用登入與座位、值日生修復

- 正式登入只保留一個密碼／身分證輸入框，後端辨識導師、任課教師、幹部與學生；任課教師沿用已設定的登入碼與原權限，不再需要切換登入分頁。
- 任課教師登入後預設顯示座位表並立即下載大頭照。照片資料與其他效果分開回傳，照片下載完成立即重繪；只有含照片的快取才送出版本號，讀取失敗會顯示提示。
- 值日生頂端座號不再呼叫其他檔案作用域的 parseKey，修復值日生頁面被錯誤阻斷。
- 補齊學生與幹部的 sellItem API 權限，沿用本人庫存檢查；任課教師仍不可賣出道具。

## 頂端值日生排版

- 資料科、多媒科各自顯示完整科別與座號標籤；科別及其座號不拆行，手機使用兩列對齊，桌面可同行。
- 保留點選進入值日生管理；使用輔助閱讀標籤完整說明名單。
